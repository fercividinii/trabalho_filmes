# trabalho_filmes
O projeto consiste no desenvolvimento de um sistema para gerenciamento e organização de filmes. O sistema permitirá cadastrar filmes, armazenar informações como título, gênero, ano de lançamento e duração, além de possibilitar a consulta dos filmes cadastrados.

Os usuários também poderão avaliar os filmes e adicionar comentários, facilitando a organização e a consulta das informações. O sistema contará com diferentes tipos de filmes, como ação, comédia e terror, utilizando os conceitos de Programação Orientada a Objetos (POO), como classes, objetos, encapsulamento, herança e polimorfismo.
