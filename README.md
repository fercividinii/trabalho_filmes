# trabalho_filmes
O software será um sistema para **cadastrar e gerenciar filmes**. O usuário poderá cadastrar, buscar, atualizar, remover e listar filmes.
Cada filme terá informações como **título, ano, duração e diretor**, além de diferentes tipos: **ação, comédia e terror**, que possuem características próprias.

O sistema utilizará **POO**, aplicando conceitos como **encapsulamento, herança e polimorfismo**, com os filmes armazenados em uma ArrayList.
