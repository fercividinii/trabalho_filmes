# trabalho_filmes
O software consiste em um sistema de gerenciamento de filmes, permitindo ao usuário realizar operações de cadastro, consulta, atualização, remoção e listagem de filmes. Cada filme possuirá informações como título, ano de lançamento, duração e diretor, além de ser classificado em diferentes categorias, como ação, comédia e terror, que apresentarão características específicas.

O desenvolvimento do sistema será baseado nos conceitos de Programação Orientada a Objetos (POO), utilizando encapsulamento, herança e polimorfismo para promover organização, reutilização e manutenção do código. Os filmes serão armazenados em uma estrutura de dados do tipo ArrayList, permitindo o gerenciamento eficiente dos registros.
