# trabalho_filmes

Projeto desenvolvido para a Aula 2 - Estrutura Base (Classes e Encapsulamento).

O sistema permite cadastrar, buscar, atualizar, remover e listar filmes em memória utilizando `ArrayList`.

## Estrutura

- `Filme.java` - classe base.
- `FilmeAcao.java` - filme de ação, utilizando herança.
- `FilmeComedia.java` - filme de comédia, utilizando herança.
- `FilmeTerror.java` - filme de terror, utilizando herança.
- `Catalogo.java` - responsável pelo CRUD em memória.
- `Main.java` - execução e testes do sistema.

Não é utilizado banco de dados nesta etapa.
